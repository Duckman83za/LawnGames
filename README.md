# Lawn Game Rentals - website

Static site for www.lawngamerentals.co.za, generated by `build.py` and deployed to cPanel by GitHub Actions on every push to `main`.

## Editing

| To change… | Edit |
|---|---|
| A game's price, description, rules or FAQs | `content/games.json` |
| Occasion pages (weddings, corporate, birthdays) | `content/occasions.json` |
| Homepage FAQ | `content/faq.json` |
| Areas delivered to | `content/areas.json` |
| Homepage sections other than the game cards | `templates/home.html` |
| Header, footer, analytics, WhatsApp button (all pages) | `templates/base.html` |
| Styles | `static/css/site.css` |
| Images, `.htaccess`, `robots.txt` | `static/` |

**Never edit `dist/`** - it is rebuilt from scratch on every build.

## Building locally

```
python3 build.py            # writes dist/
python3 build.py --zip      # also writes lawngamerentals-site.zip for manual upload
cd dist && python3 -m http.server 8777
```

No dependencies beyond Python 3.

## Deploying

Push to `main`. The workflow in `.github/workflows/deploy.yml` builds the site and uploads `dist/` over FTPS. It needs three repository secrets: `FTP_SERVER`, `FTP_USERNAME`, `FTP_PASSWORD`.

## Adding a game

Add an entry to `content/games.json` with the same fields as the others, drop the photo into `static/images/` as `<name>.png`, and create the `.webp` and `-400.webp` variants (`cwebp -q 82` at 800px wide, `-q 80` at 400px). The homepage card, the game page, the sitemap and the structured data are all generated from that one entry.
